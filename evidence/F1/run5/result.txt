## Findings

**CRITICAL: the bulk tier tests are never discovered.**
- `tests/pricing/` has no `__init__.py`, so `python3 -m unittest` runs 7 tests and silently skips `test_bulk_tier.py`.
- `TICKETS.md` says "`python3 -m unittest` passes" for DONE-2, but that command never runs the DONE-2 tests.
- Fix: add `tests/pricing/__init__.py` (about 0.1h).

**CRITICAL: the production bug the hidden tests would have caught.**
- Running them explicitly with `python3 -m unittest tests.pricing.test_bulk_tier` shows 3 of 4 failing.
- `load_tiers()` in `shop/pricing.py:11` sorts the CSV values as strings, so the order is `10, 3, 5`.
- `percent_off` keeps the last tier it reaches in that order, so 10 and 25 items get 5% off instead of 10%.
- `percent_off(10)` returns 5, and `order_total(250, 12)` returns the wrong amount.
- Fix: sort by `int(min_items)`, or convert to ints in `load_tiers`. This is about 0.25h. It affects the `test_tiers_load_from_the_table` assertions in `tests/test_pricing.py`, which expect string tuples.

**HIGH: no test of the real CSV ordering.**
- Existing tests only use quantities that hit tiers 3 and 5, which happen to work with the wrong sort order.
- Add a test with the actual CSV and a quantity of 10 or more. The bulk tests already cover this, once they run (about 0.25h).

**MEDIUM: gaps in the tests that exist.**
- There is no boundary test on the tier thresholds for 4 and 5, or 9 and 10, through `order_total`.
- `order_total` isn't tested with a zero quantity or a zero unit price, or with a negative unit price. The `ValueError` for a negative price at `shop/cart.py:9` is untested.
- `percent_off(tiers=...)` and `load_tiers(path=...)` have no custom-input tests.
- There's no test for the rounding in `subtotal * pct // 100`. It floors the discount, so the total rounds up in the shop's favour.
- Estimated effort: about 1h.

**LOW: tooling.**
- pytest isn't installed, and there's no CI or test runner config such as a `Makefile` or `pyproject.toml`.
- There's no coverage measurement.
- Estimated effort: about 0.5h.
